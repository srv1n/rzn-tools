# ADS-T-0004 · Competitor ad intel report command (end-to-end)

## Intent

The sellable artifact: one command that takes a list of competitor advertisers and produces a client-ready markdown report — longevity leaderboard (long-running ads are proven winners), creative format mix, clustered hooks/angles/offers, per-competitor summaries, and a recommendations stub. This is what tools like Foreplay/AdSpy charge $99–250/month for; here it is bundled into the agent-in-a-box.

The command consumes a captured directory (`ads-manifest.json` + assets from the rzn-browser ADI packs) and the per-ad analysis from ADS-T-0001. When the rzn-browser CLI is installed it MAY orchestrate a fresh capture; it MUST also work on a pre-captured directory so the fixture path never depends on live sites.

## Dependencies

- Hard: ADS-T-0001 (analysis pipeline) — this task starts only after its output schema is stable.
- Soft: rzn-browser ADI-T-0001/0002 for the live-capture path; fixture path works without them.

## Scope

In:
- Command accepting a run config: advertisers, source (meta/google/both), country, capture dir, output path.
- Report generator: longevity leaderboard, format mix, hook/angle/offer clusters, per-competitor sections, "gaps and opportunities" stub for the operator to finish.
- Graceful degradation: missing assets, missing transcripts, or partial captures produce a report with explicit "not captured" notes rather than failures.
- Fixture-path end-to-end test with golden report.

Out:
- Scheduling/recurrence (platform concern, not this command).
- PDF rendering.
- Any writing back to ad platforms.
