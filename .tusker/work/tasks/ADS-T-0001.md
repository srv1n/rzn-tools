# ADS-T-0001 · Creative analysis pipeline for downloaded ad assets

## Intent

Turn a directory of captured competitor ad creatives into structured, sellable insight. Input is an `ads-manifest.json` plus asset files produced by the rzn-browser ADI packs (ADI-T-0001/0002 in the rzn-browser vault). Output is per-ad analysis JSON (transcript, visual description, extracted hook/angle/offer/CTA) and an aggregate longevity-weighted "what's working in this niche" markdown report. This is the analysis half of the competitor ad-intel product; capture is owned by rzn-browser.

Develop entirely against local fixtures. Do not depend on live capture or live third-party sites.

## Input contract (shared with rzn-browser ADI epic)

`ads-manifest.json` — canonical definition lives in rzn-browser ADI-T-0001; mirrored here for the consumer side:

```json
{
  "source": "meta_ad_library | google_ads_transparency",
  "captured_at": "ISO-8601",
  "query": { "advertiser": "...", "keyword": "...", "country": "US" },
  "ads": [{
    "id": "library ad id",
    "advertiser": "page or advertiser name",
    "started_at": "YYYY-MM-DD or null",
    "active": true,
    "platforms": ["facebook", "instagram"],
    "media_type": "video | image | carousel | text",
    "copy": "primary text or null",
    "headline": "string or null",
    "cta": "string or null",
    "landing_url": "url or null",
    "assets": [{ "kind": "video|image", "path": "assets/<id>-<n>.<ext>", "source_url": "..." }]
  }]
}
```

Treat every field except `id` and `source` as nullable; Google Transparency Center surfaces less than Meta.

## Scope

In:
- Manifest reader + schema validation with a helpful error on drift.
- Video transcription via a configurable backend (local whisper binary or hosted API), following the repo's existing provider-config patterns; no hardcoded keys.
- Image / video-keyframe description via a configurable vision-capable LLM provider.
- Per-ad analysis JSON: transcript, visual summary, hook, angle, offer, CTA, target-audience guess.
- Aggregate markdown report: longevity leaderboard (days running from `started_at`), media-format mix, clustered hooks/angles/offers, per-advertiser summary.
- Feature-gated CLI command(s) in `rzn_tools_cli`; fixtures and tests.

Out:
- Any scraping or capture (rzn-browser ADI epic owns it).
- Campaign management or any write action against ad platforms.
- Report PDF rendering (markdown is the deliverable for now).

## Non-goals

- No live fetching from Meta or Google surfaces.
- No automatic posting or outward action of any kind.
- No provider lock-in: transcription and vision backends must be swappable via config.
