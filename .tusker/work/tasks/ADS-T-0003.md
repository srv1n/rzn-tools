# ADS-T-0003 · Google Ads API connector (read-only GAQL reporting)

## Intent

Read-only reporting connector for a client's own Google Ads accounts. Core surface is GAQL via the REST `searchStream` endpoint: canned reports (campaign performance, ad group performance, ad performance, search terms) plus a raw GAQL passthrough for advanced queries. Auth is OAuth2 refresh token + developer token + customer id from env/config.

Follow existing connector conventions: module under `rzn_tools_core/src/connectors/google_ads/`, feature flag `google-ads` in `all-connectors`, icon, README and `manifest.json` rows.

Prefer the REST endpoint over the gRPC client library to avoid a heavy dependency tree; document the choice in the connector module.

## Scope

In:
- Auth: OAuth2 refresh-token flow (token refresh handled by the connector), developer token, login-customer-id/MCC support.
- Canned reports as typed commands: campaign perf, ad group perf, ad perf, search terms — each with date range presets and custom ranges.
- Raw GAQL passthrough command with pagination.
- Error mapping for the common failures (developer token not approved, invalid customer id, OAuth expiry) to actionable messages.
- Fixture-based tests from recorded `searchStream` responses; docs, icon, `.env.example` keys.

Out:
- All mutations (campaign edits, budget changes, keyword changes).
- Keyword Planner / reach forecasting (possible future task).
- Ads Transparency Center (owned by rzn-browser ADI-T-0003; it has no API).
