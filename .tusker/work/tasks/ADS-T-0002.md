# ADS-T-0002 · Meta Marketing API connector (read-only insights)

## Intent

Read-only reporting connector for a client's own Meta ad accounts via the Marketing API: list campaigns/ad sets/ads with status and objective, and query the insights endpoint (spend, impressions, clicks, CTR, CPM, conversions/ROAS where available) with date ranges, levels, and breakdowns. This powers "weekly ad performance digest" agent workflows.

Follow existing connector conventions exactly: module under `rzn_tools_core/src/connectors/meta_ads/`, feature flag `meta-ads` wired into `all-connectors` in Cargo.toml, icon in `resources/icons/connectors/`, rows in README and `manifest.json`. Auth via a long-lived system-user access token from env/config.

## Scope

In:
- Auth: system-user access token (env/config), token validation/`me` check command.
- List: ad accounts, campaigns, ad sets, ads (id, name, status, objective, created/updated).
- Insights: level (account/campaign/adset/ad), date range + presets, core metrics, at least one breakdown dimension (e.g. publisher_platform).
- Pagination and Graph API error mapping (rate limits, expired token) to actionable messages.
- Fixture-based tests from recorded responses; docs, icon, `.env.example` keys.

Out:
- ALL write operations — no budget changes, no pausing, no creative uploads. Deferred until approval-gate infrastructure exists.
- Ad Library / competitor research: the official API only covers political and EU-targeted ads, so that surface is owned by the rzn-browser ADI packs.
