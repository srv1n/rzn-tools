# Glossary

- **Connector**: Code that reads or writes one data source.
- **Registry**: The core map from connector names to connector instances.
- **Tool**: One operation exposed by a connector.
- **Feature**: A Cargo switch that includes code in a build.
- **Profile**: A named group of connectors for federated search.
- **Normalized output**: A stable result shape for agents and downstream code.
- **MCP**: Model Context Protocol, used to expose tools to an MCP client.
