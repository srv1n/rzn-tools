# Project overview

<!-- tusker:overview:begin -->

`rzn-tools` is a local Rust integration layer. It gives shell users, MCP
clients, and Rust programs one connector model for many data sources.

This project contains the shared core library, the CLI, the MCP server, source
connectors, install assets, examples, and system documentation. Provider
credentials and personal data stay outside the repository.
