# Assistant contribution policy

AI-assisted work is allowed.

What is not allowed is submitting code that the human contributor does not understand.

## When an assistant is used

- say that an assistant was used
- name the assistant when it matters
- state what it changed
- check the final behavior
- resolve review comments with intent

## Not required

- full transcripts for every change
- giant prompt dumps
- performative process theater

Use a short summary instead of a full transcript. A summary does not replace
tests, review, or proof of behavior.
